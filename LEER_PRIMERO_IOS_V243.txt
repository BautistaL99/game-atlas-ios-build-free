CAMBIOS REALIZADOS EXCLUSIVAMENTE EN IOS:
1) CORRECCIÓN DEL ÚNICO ERROR NUEVO: cambiar de marcador A a marcador B.
   Antes: touchend/pointerup cerraban la ficha A antes de llegar el click del pin B; se necesitaban dos toques.
   Ahora: un toque sobre otro pin o agrupación conserva el click de selección y puede abrir la siguiente ficha inmediatamente.
   Tocar el fondo del mapa sigue cerrando la ficha. Arrastrar sobre un marcador sigue permitido y no debe abrirlo por accidente.
2) ACTUALIZACIONES FIRMADAS DEL MAPA: el validador de fichas y recorridos admite el ID del mapa firmado activo,
   además del provisional. Cuando se activa una nueva cartografía firmada, solicita un nuevo control del catálogo.
   No se ha reemplazado la imagen ni las posiciones actuales y NO existe aún un mapa definitivo publicado.
3) FICHAS WIKI: el cliente iOS quedó preparado para categorías comunitarias firmadas adicionales:
   misiones, secretos, coleccionables, economía, actividades y mundo.
   Ya admitía personajes, vehículos, armas y lugares. El PUBLICADOR EXTERNO debe generar esos nuevos datos,
   de fuentes permitidas y con las tres traducciones; aquí NO se inventaron fichas ni se cambiaron firmas.
4) PRUEBAS AUTOMÁTICAS: scripts/qa-marker-switch.mjs y scripts/qa-ios-audit.mjs.
   El workflow TestFlight las ejecuta antes de compilar. Una regresión impedirá enviar una IPA sin advertencia.

RESULTADOS DE AUDITORÍA:
- 29 archivos JavaScript comprobados, sin errores de sintaxis; recursos locales y gestos nativos comprobados por los scripts.
- 55 fichas base con ID único y título/resumen en español, inglés y portugués.
- Feed oficial público: esquema 1, revisión 4, 19 entradas, más reciente 10/11/2026.
- Feed independiente público: esquema 205, revisión 18, 26 noticias y 406 fichas; noticias hasta 16/11/2026.
  Distribución de fichas: 250 vehículos, 95 personajes, 47 armas y 14 lugares.
- Ambos feeds se consumen mediante firma Ed25519 con validadores de fuentes, pero esta auditoría NO prueba
  que cada actualización se esté recibiendo correctamente dentro del iPhone.
- Rutas: se pueden crear, ordenar, guardar y representar como líneas; todavía NO siguen las calles del juego.
- Mapa: el paquete remoto requiere imagen permitida, SHA-256, esquema válido y firma, pero actualmente no hay
  manifiesto nuevo de mapa publicado. No completar ni afirmar ubicaciones que no estén verificadas.
- Buscadores ES/EN/PT: estructura disponible, NO se comprobó cada frase semántica ni cada modelo en un dispositivo.
  Las fichas base de vehículos no incluyen velocidades numéricas para rankings auténticos.
- Donaciones Mercado Pago: paymentEnabled=false y enlace público no configurado. Ranking de donaciones sin datos.
- Publicidad: no se implementó. Versión sin anuncios por pago: tampoco; requeriría compras dentro de la app.
- Enlaces públicos App Store / Google Play en la sección Descargas: actualmente vacíos, se activan al publicar.
- Marca: la UI muestra Game Atlas GTA 6 y la ficha Apple Game Atlas: Wiki & Map; revisar consistencia antes de capturas.
- SEO de Google, Google Play, web PC/móvil y subir a Drive NO se modificaron: están fuera del alcance iOS.

PRUEBA REAL OBLIGATORIA EN IPHONE (DOS MODOS: MAPA NORMAL Y PANTALLA COMPLETA):
[ ] Tocar marcador A y luego marcador B: se abre B CON UN SOLO TOQUE, sin cerrar antes ni desplazar el mapa.
[ ] Tocar sucesivamente cinco marcadores diferentes: cinco fichas distintas.
[ ] Tocar la zona vacía: se cierra la ficha sin saltos de zoom.
[ ] Tocar una agrupación: agrupa/acerca como antes; no requiere toque doble.
[ ] Arrastrar con el dedo desde un marcador: mueve el mapa sin abrir accidentalmente fichas.
[ ] Crear, editar, guardar y cerrar un marcador; probar abrir/cerrar teclado.
[ ] Buscar "play" / "playa", "beac" / "beach" y "prai" / "praia"; comprobar sugerencias y fichas.
[ ] Buscar "auto más lento": ver fichas relacionadas y aviso si no hay estadísticas verificadas.
[ ] Seleccionar tres vehículos para Comparar: abre pantalla comparativa, no Explorar.
[ ] Cambiar Todos / Me faltan / Registrados / Favoritos en Explorar sin saltos involuntarios.
[ ] Cambiar idioma ES/EN/PT y revisar Noticias, Explorar, Mapa, Mi partida y Más.

INSTALACIÓN EN TESTFLIGHT:
1. Abrir el enlace WORKFLOW indicado arriba, clic en Run workflow.
2. Seleccionar Use workflow from = qa-ios-v243. NO seleccionar main.
3. Dejar versión pública iOS = 1.0 y pulsar Run workflow.
4. Si GitHub termina en verde, abrir App Store Connect > Apps > Game Atlas > TestFlight.
5. Esperar al procesamiento de la nueva build; completar información de exportación si Apple la pide.
6. Añadir nueva build al grupo Game Atlas - Pruebas internas si hace falta.
7. En el iPhone, TestFlight > Game Atlas > Actualizar. Repetir la lista de pruebas.
8. NO enviar a revisión final si el error persiste o aparecen fallos nuevos.
